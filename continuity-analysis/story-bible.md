## React Concepts Map

### Components Basics (Learning Path 1)

**1.1 ComponentKingdom**
- **React Concepts**: 
  - Components as reusable, self-contained pieces
  - Component hierarchy (App as root/master builder)
  - Single responsibility principle
  - Component composition
  - Props basics (⚠️ introduced too early - belongs in 1.2)
- **Story Elements**: 
  - Workshops (represent components)
  - Master builder App in tallest tower
  - Northern Quarter's Component Workshop District
  - Craftsmen with special purposes
- **Metaphor Quality**: ✓ Excellent - workshops as specialized creators maps perfectly to components
- **Technical Accuracy**: ✓ All concepts correct, but Props introduced prematurely

**1.2 PropsMessengers**
- **React Concepts**:
  - Props as data passed from parent to child
  - Unidirectional data flow (parent → child only)
  - Props are read-only/immutable
  - Multiple prop types (string, number, boolean, function, array, object, component)
  - Callback functions for child → parent communication
  - PropTypes for type validation
  - DefaultProps for fallback values
- **Story Elements**:
  - Messengers carrying satchels (props)
  - Props Messenger Guild
  - Grand Thoroughfare (one-way roads)
  - PropTypes Guardians inspecting deliveries
  - Guardian TypeCheck with type symbols
- **Metaphor Quality**: ✓ Excellent - messengers delivering sealed instructions maps well to props
- **Technical Accuracy**: ✓ All concepts correct and well-explained

**1.3 JsxMagic**
- **React Concepts**:
  - JSX syntax (HTML-like markup in JavaScript)
  - Babel transpilation (JSX → JavaScript function calls)
  - Embedding JavaScript expressions with curly braces {}
  - JSX rules (mentioned but not detailed in Story Groups)
- **Story Elements**:
  - Grand Library with glowing scrolls
  - Professor Syntaxis (wise mage)
  - Babel (translator sprite)
  - Binary sprite (evaluates expressions)
  - Curly Brace Incantation (portals between markup and JavaScript)
  - Expression Playground
  - Tablets with JSX rules
- **Metaphor Quality**: ✓ Good - magical language requiring translation fits JSX/Babel concept
- **Technical Accuracy**: ✓ Concepts correct, though JSX rules incomplete in Story Groups

**1.4 LifecycleChronicles**
- **React Concepts**:
  - Component lifecycle concept
  - Three phases: Mounting, Updating, Unmounting
  - Mounting methods: constructor → render → componentDidMount
  - Updating methods: shouldComponentUpdate → render → componentDidUpdate
  - Unmounting method: componentWillUnmount
  - Cleanup importance (timers, listeners, subscriptions)
  - Memory leak prevention
- **Story Elements**:
  - Lifecycle Sanctum
  - Floating hourglasses (represent component lifecycles)
  - Chronos (Master Time Keeper)
  - Luminous murals chronicling phases
  - "Ghost timers" and "phantom listeners" (memory leaks)
  - Binary's flower metaphor (seed → bud → bloom)
- **Metaphor Quality**: ✓ Excellent - time/lifecycle metaphor is intuitive and memorable
- **Technical Accuracy**: ✓ All lifecycle methods explained correctly
- **Note**: Teaches class component lifecycle (not hooks). Modern React uses useEffect for lifecycle in functional components. May feel outdated but valuable for understanding React fundamentals and legacy code.
