## Git Workflow

- **Always use `git add .`** before committing to catch all changes in the working directory
  - Avoids missing files that were created or modified
  - Ensures complete commits

## Review Process Reminders

### Character Appearance Rules
- **Characters should NOT return across Learning Paths**
- Previous teachers/characters can be MENTIONED (e.g., "Master Aurelius taught you about components")
- But they should NOT appear as active participants in new Learning Paths
- Each Learning Path should have its own cast of characters/teachers
- Exception: Aria and Binary travel through all Learning Paths as main characters
